# 实验 9：大模型改写的鲁棒性

用 DeepSeek（deepseek-chat）把邮件改写成语气自然、像真人写的版本，保持原意、请求和链接不变。
钓鱼组的数字是**召回率**（越高越好），正常组的数字是**误报率**（越低越好）。阈值为各模型在验证集上选出的阈值（误报率 ≤ 1%）。

被模型拒绝改写的样本：{'test_en_phish': 0, 'test_zh_phish': 1, 'test_en_ham': 1, 'test_zh_ham': 0}

| 系统判定（TF-IDF v2 校准 + 规则，≥50） | 0.985 | 0.980 | -0.005 |
| TF-IDF v2 | 0.985 | 0.980 | -0.005 |
| DistilBERT v2 | 1.000 | 1.000 | +0.000 |
