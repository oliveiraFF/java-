# 基线实验结果：TF-IDF + 传统机器学习（目标：钓鱼 vs 非钓鱼）

数据：训练 79228 / 验证 11209 / 测试 22393 封；钓鱼专项测试子集 12551 封；TF-IDF 词表 150000。
特征：主题 + 正文，词级 1–2 gram，sublinear TF，max_features=100k。
正样本只有钓鱼与诈骗邮件；垃圾/营销邮件和正常邮件都是负样本；分类器使用类别平衡权重。

## 5. 模型最依赖的词（可解释性示例）

**朴素贝叶斯**
- 偏向恶意：usaa、核验、快核、击链、免影、号将、税退、参保、验地、款账、发金、予办、需尽、逾期、税尚
- 偏向正常：replica、python、watches、2008、ect、么、enron、rolex、vince、hou、livefilestore、classics、cable、去、真

**逻辑回归**
- 偏向恶意：jose、monkey、2016、dear、2022、2017、usaa、5m、administrator、kindly、account、expire、2020、utf、2018
- 偏向正常：th、enron、2008、lottery、net、linux、site、com、receipts、ie、free、http、see、available、ilug

**线性 SVM**
- 偏向恶意：jose、monkey、2016、2017、2022、administrator、usaa、2020、2018、dear、kindly、expire、5m、account、outlook
- 偏向正常：th、lottery、enron、2008、receipts、linux、ie、net、ilug、site、available、spamassassin、lasalle、free、ebay

**随机森林**
- 重要性最高：account、your、dear、jose、million、monkey、http、assistance、funds、请、business、将、please、bank、my

最佳模型（按全量测试集 F1）：**线性 SVM**
